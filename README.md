How to run the multithreaded array sorter.
1. Have Java installed (I used JDK 21 to compile it but most should be fine)
2. Unzip the folder with the code, jar file, example text file, and readme
3. Open terminal to that folder.
4. Type 'java -jar multithread.jar'
5. Leave blank for default numbers.txt input, or type a different file name for other input. 
    Make sure the file is in the same folder as multithread.jar
6. Program should run and output the sorted array.
